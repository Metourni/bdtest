# Happy Birthday

Mobile-first birthday page with a Marine Serre–inspired look: crescents, black/moon palette, fashion-editorial type.

## Share a link

Pass the name as a query param:

```
https://metourni.github.io/bdtest/?name=Sofia
```

Optional: `&age=25` and `&message=Your%20note%20here`

## Local

Open [`index.html`](index.html) or:

```bash
npx --yes serve .
```
